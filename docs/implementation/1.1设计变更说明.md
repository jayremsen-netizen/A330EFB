# A330EFB 1.1 设计变更说明

本文记录相对 `5df1664` 的设计变化。机型和上游提交保持不变；本地扩展位于 `local-extensions`，宿主和演示位于 `local-efb`。构建时由 `integrate_extensions.py` 将本地组件接入原有路由，生成目录仍不进入版本控制。

## 1 领域数据与宿主

`Flight` 表示拟采用的业务输入，确认身份由输入和资料版本的签名共同构成。`State.result` 可以保留过期记录供查看；`currentResult()` 只有在输入、确认身份、地面目标及保存状态均有效时才返回可导出的结果。天气采用经过 `editFlight()`，与手工输入具有相同的失效规则。

`units.ts` 为规范单位和请求单位之间提供换算。变量注册记录名称和单位，直接读写、注册读写和 Coherent 写入使用同一路径；燃油体积与质量换算采用当前宿主密度。未知的无量纲本地变量保留数值，不推断物理量。`fuel.ts` 的分配顺序为内侧首段、外侧、内侧剩余、中央，容量 36743 US gal，对应演示密度下的 111661.977 kg。

计划确认首先同步原生签派与目标数据。尚未开始地面演练时，以确认计划初始化本地当前状态；开始地面操作后，再次确认只更新目标，当前数量由运行模型推进。停机预设将当前油量置为 5000 kg、人数与货物清零，准备预设使用已确认计划。两种预设均重建会话。

## 2 保存协议

`persistence.ts` 将草稿结构校验与完整业务校验分开。数值空白序列化为 `null`，恢复后成为空白输入；确认必须通过完整校验。历史与当前结果分别校验，当前版本结果重新计算并逐项比对。旧版本合法记录可以作为历史显示，但不能恢复为当前确认。

恢复失败时，原始字符串写入带时间戳的恢复键；异常历史项不进入显示列表。导出恢复备份保留原始内容，后续普通保存不覆盖备份。保存失败时页面显示错误并提供航班导出，不能声称已经持久化成功。

窗口使用上次读到的存储文本作为版本标记，在写入前比较，同时监听其他窗口的 `storage` 事件。冲突窗口停止后续写入和报告导出，保留内存草稿，可导出或读取最新版本。该机制是单机乐观冲突检测，不是数据库事务或跨设备协作协议。

## 3 本地运行模型

`DemoRuntime` 独立于 React 和浏览器 API，通过 `submit`、`tick`、`fault`、`cancel`、`reset` 推进状态。命令包含 `id`、`session`、类型、参数、时间、进度与回执。回执依次进入已受理、执行中、完成，或在前置条件不足时拒绝；故障和停止操作中止执行并保留当前进度。

每个会话保存最多 1000 个命令标识以保证重试幂等，界面保留最近 100 条记录并显示最近 12 条。达到会话上限时要求复位。重置更换会话标识并清空未完成动作，带旧会话号的请求被拒绝。模型由单一 100 ms 定时器调用 `tick`，没有每条命令的悬挂回调。

`runtime-host.ts` 将快照中的油量、人数、货物与电源状态写入本地宿主变量，并通知 React 页面。加油和登机读取已确认计划；源页面的目标变更必须带回航班确认后执行。推出要求电源断开且没有其他进行中的请求，完成后状态为 30 米示意距离。原生燃油和登机开始标志也接入本地模型。

电源故障立即断开当前电源并阻止新连接；加油故障中止加油并保留已经变化的油量。解除故障只恢复服务可用性，不重新执行旧请求。模型不包含发动机、电气网络、液压网络或地面物理运动。

## 4 资料与天气

图件目录仅引用本项目自制 SVG。收藏记录只存图件标识；用户选择的 PDF、PNG 或 JPEG 通过对象地址在当前页面会话读取，离开后不持久化原文件。导入采用文件大小、文件特征和图片解码检查；异步导入使用序号避免旧请求覆盖新选择。对象地址在替换或卸载时释放。

PDF 采用 npm 锁定引用的 PDF.js 6.4.299，工作线程、字库和解码资源随构建提供，无需 CDN。载入前解析文档，失败时保留原图；显示时按页渲染 canvas，切换页码或旋转会取消旧绘制，避免旧页面覆盖新页面。实现依据 [Mozilla PDF.js 官方示例](https://mozilla.github.io/pdf.js/examples/)，页面上不执行 PDF 附带脚本或表单动作。

天气是固定样例对象，包含机场、时间、报文和结构化参数。采用时写入来源标识；手工改动天气后去掉原样例来源。向原生签派提供报文前核对所选样例与当前参数，避免已经修改气压却继续展示旧报文。

## 5 性能防护与验证

着陆系数保留上游实现，新增输入和输出守卫。190000 kg 以外的重量（允许显示换算带来的 0.5 kg 舍入误差）不输出距离；非有限或非正结果也被撤销。清空结果在页面显示破折号。该措施规避已发现的负距离，不能推导为其余参数已经过航空性能校准。

CONF 3 的 220–230 t 区间不输出 V2，既有正常节点和插值回归仍保持。新增质量上限、日历日期、必填身份与跑道编号校验，使拒绝发生在确认入口。验收以 `tests/reliability-tests.cjs`、`tests/reliability-ui-tests.cjs` 和四套场景的实际执行记录共同证明。
